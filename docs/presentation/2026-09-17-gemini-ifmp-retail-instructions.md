# IFMP Retail · Gemini 簡報生成指令

**用途：** 將本文件整份貼入 Gemini，生成對 **I.T. 時裝零售** 的 IFMP Retail 平台介紹簡報。
**產出：** 一個 `.pptx`（18 頁）。生成後需人手套回公司模板。
**對象：** I.T. 時裝零售（香港）— 已進行試點之客戶
**投影片語言：** 香港繁體書面語（非粵語口語）
**版本：** v1.0 · 2026-09-17

---

## 使用說明（本節不是貼入 Gemini 的部分，貼之前請刪走）

1. 先做 **Part B 模板代幣表**：開公司 `.pptx`，抄下 12 個值填入空欄。
2. 由 `## Part A` 開始，連同 Part A／B／C／D 一併複製，貼入 Gemini。
3. Gemini 第一輪只會回頁目錄，等你講「批准」才生成。這是刻意設計。
4. 生成完，在 PowerPoint 將真模板套上（Part B §4）。

---

## Part A · 角色與硬規則

### A1 · 你的角色

你是一個簡報製作員，不是文案創作人。內容已經定稿，你負責**排版、分頁、視覺層次**，以及按指定文案生成投影片。

### A2 · 第一輪：先回頁目錄，不得生成

**收到本文件後，你第一輪只准輸出以下內容，然後停下來等我回覆：**

1. 18 頁的頁碼與標題清單
2. 每頁一句話摘要（不超過 20 字）
3. 你打算用的版式類型（例如：封面／全幅截圖＋側註／三欄對照／純文字／表格）
4. Part B 有沒有未填的空格

**不得**在第一輪生成 `.pptx`、不得起草正文、不得詢問 Part C 以外的內容問題。

我回覆「批准」之後，你才可以生成。

### A3 · 硬規則（任何情況不得違反）

| 編號 | 規則 |
|------|------|
| R1 | **模板優先。** 只用 Part B 代幣表記載的顏色、字體、logo 位置。不得自創品牌色、不得自選字體、不得加裝飾圖案。 |
| R2 | **不得改動內容。** Part C 每頁的標題與正文視為定稿。你可以調整排版，但不得增刪、改寫、重排、加頁、減頁。 |
| R3 | **不得虛構。** 不得發明數據、客戶名稱、案例、獎項、認證、合作品牌。 |
| R4 | **不得報價。** 任何價格、費用、折扣、優惠數字一律不得出現。套餐只講包含範圍，不講金額。 |
| R5 | **不得承諾日期。** 不寫上線日、交付日、發佈日。 |
| R6 | **不得點名競品。** 只可用類型對照（「純硬件計數器」「通用零售 BI」），不得寫出任何品牌名。 |
| R7 | **不得聲稱人臉識別。** 不得寫「辨識顧客身份」「會員識別」「人臉比對」或同義表述。 |
| R8 | **不得聲稱空調控制。** 節能只可講監測與建議。不得寫「自動控溫」「控制中央空調」。 |
| R9 | **樣本資料聲明。** 凡出現產品畫面的頁，必須保留 `示範畫面 · 樣本資料` 角標。 |
| R10 | **語言。** 投影片正文一律香港繁體書面語。不得出現粵語口語字（咗、嘅、喺、唔、係、嗰、啲）。講者備註可以用粵語描述口頭演繹。 |
| R11 | **不得壓縮中文。** 中文字號不得小於 16pt，行距不得小於 1.3。若文字溢出，改版式或分欄，不得縮字。 |
| R12 | **整體一致。** 全份簡報只用 Part B 的一套字體與色票。不得個別頁換色或換字。 |

### A4 · 產品事實（唯一可用事實來源）

不得引用本節以外的事實。

- **平台名稱：** IFMP Retail
- **平台副題：** 零售營運主控台
- **交付方：** HKIT 智域
- **感知技術夥伴：** 百度一見
- **客戶：** I.T. 時裝零售（香港）
- **示範門店標識：** I.T. 銅鑼灣
- **架構分工：** 門禁計數與店內攝像 → 一見邊緣盒（偵測、追蹤、區域停留、推事件）→ IFMP（聚合、規則、看板、告警）→ 店長工作流程
- **已上線畫面（可截圖）：** 主控台、動線熱力、出入口、客群畫像、同期對比、節假日、排班（週板／員工名冊／更表模板／工時政策／調更審批／審計）、設備、設定
- **未上線能力（只可寫入路線圖頁，不可造假截圖）：** 服務缺口告警、一鍵調度、服務教練、AI 分析、平台問答、POS 對接、多店對標、能源監測、能源聯動
- **服務缺口規則（構想，未上線）：** 高停留區域連續約 2 分鐘無人服務即判斷為缺口，門檻可配置
- **首輪接觸目標（構想，未上線）：** 可配置目標秒數，預設 90 秒
- **排班構想：** 依歷史客流建議每小時應到人數，店長可調整
- **能源立場：** 具備設備控制權方可談聯動；現階段只監測

### A5 · 示範資料聲明

本簡報全部產品畫面來自示範環境，使用樣本資料，並定格於 **2026-09-16**。凡出現畫面之頁，右下角固定放：

```
示範畫面 · 樣本資料
```

字號 10–12pt，與頁腳同色系。

### A6 · 版面通用要求

- 頁碼放右下，由第 2 頁開始編號。
- 標題統一放頁面上方，左對齊。
- 每頁只講一件事。正文不超過 6 行或 6 個要點。
- 表格線條用代幣表的次要中性色，不用預設黑框。
- 圖表不得自製假數據。需要圖表的頁一律用 `[[SHOT: ]]` 佔位。
- Logo：封底與封面用橫向鎖定組合，內頁頁腳用小圖標。

以下檔案可直接使用，位於 repo `public/brand/`：

| 檔案 | 用途 |
|------|------|
| `logo-lockup-light.png` | 淺底用橫向鎖定組合（封面、封底） |

不得自行重繪、變形、加陰影或改色。

### B3 · 色與字使用規則

- 標題：`COLOR_TEXT` 或 `COLOR_PRIMARY`，二選一後全份沿用。
- 重點數字：`COLOR_ACCENT`，每頁最多一處。
- 次要說明、頁腳、樣本聲明：`COLOR_MUTED`。
- 表格標題列：`COLOR_PRIMARY` 底 + 白字。
- 架構圖方塊：`COLOR_PRIMARY` 描邊 + `COLOR_BG` 底；箭頭用 `COLOR_MUTED`。

### B4 · 生成後套回真模板（必做）

Gemini 生成的 `.pptx` **不會**繼承公司模板的版面母版。生成後：

1. 開公司模板 `.pptx`，另存為新檔。
2. 在 PowerPoint 用 `常用 > 新增投影片 > 重複使用投影片`，將生成檔的 18 頁逐頁匯入。
3. 每頁套用對應版面，再按需要微調位置。
4. 確認頁腳、logo、頁碼由母版帶入，而不是生成檔的自製版本。
5. 刪走生成檔的臨時裝飾。
